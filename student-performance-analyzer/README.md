Student Performance Analyzer

A beginner Python project that analyzes student information and academic performance using lists, dictionaries, loops, and conditional statements.

Features

- Student Reports: Calculates each student's average score and assigns a performance status.
- Class Analysis: Calculates the class average, identifies the top student, and counts excellent students.
- City Analysis: Counts students from each city and identifies all cities with the highest number of students.
- Student Search: Searches for a student by name, regardless of uppercase or lowercase letters.
- Nested Data Processing: Works with lists inside dictionaries and dictionaries inside lists.

Performance Classification

Average Score| Status
18 or higher| Excellent
15 to less than 18| Good
Less than 15| Needs Improvement

Technologies Used

- Python 3
- Lists and dictionaries
- Nested loops
- Conditional statements
- String methods
- Basic data analysis

How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python student_performance_analyzer.py

5. Enter a student's name when prompted to search for their information.

Learning Objectives

This project was developed as part of my Python learning journey to practice nested data structures, loops, conditional logic, calculations, and searching through structured data.
