# Online Store Management System

## 📌 About the Project

This project is a simple online store management system developed using Python.

It manages product information and performs basic sales analysis using Python data structures, loops, and functions.

## 🚀 Features

- Calculate total sales for each product.
- Calculate revenue for individual products.
- Rank products by revenue.
- Identify products with low stock.
- Group products by category.
- Calculate total store revenue.
- Count the total number of products.
- Search for products by name (case-insensitive).

## 🛠️ Technologies

- Python
- Lists and Dictionaries
- Loops and Conditional Statements
- Functions
- Lambda Expressions
- Sorted Function

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python store_management.py
```
