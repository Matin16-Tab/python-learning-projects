Student Management System

A beginner-friendly Python project that manages student records and analyzes their scores.

Features

- Check student scores and classify them as Accepted, Rejected, or Invalid.
- Count students in each category.
- Store accepted students in a separate list.
- Identify unique cities using a set.
- Count students in each city using a dictionary.
- Search for a student by name.
- Filter students with valid scores.
- Sort students by score in descending order.
- Display student rankings.

Technologies and Concepts

- Python 3
- Variables and data types
- Conditional statements
- Functions
- Loops
- Lists
- Dictionaries
- Sets
- Sorting with "sorted()"
- Lambda functions
- Ranking with "enumerate()"

How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run the following command:

python student_management.py

The program will ask you to enter a student name and then display the search result and student statistics.

Score Classification

Score| Status

0–9| Rejected
Below 0 or above 20| Invalid
