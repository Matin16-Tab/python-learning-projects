Student Score Analysis

A beginner Python project for managing student records and analyzing their scores.

Features

- Store student information using lists and dictionaries.
- Classify scores as Accepted, Rejected, or Invalid.
- Calculate the average score of accepted students.
- Identify students who score above the average.
- Count students by city and find the most common city.
- Sort students by score and display their rankings.
- Search for a student by name.
- Use tuples and string operations to process school information.

Concepts Used

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists, tuples, sets, and dictionaries
- List copying
- Sorting with "sorted()" and "lambda"
- Iteration with "enumerate()"
- String indexing and slicing
- Basic data analysis

Technologies

- Python 3

Purpose

This project was created as part of my journey to learn Python programming, from basic concepts to working with data structures and functions.
