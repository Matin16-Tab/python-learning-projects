Bookstore Inventory & Sales Analyzer

A Python project that analyzes bookstore inventory and sales data to generate a simple management report.

:pushpin: Project Overview

This project processes bookstore data stored in a list of dictionaries. It calculates total sales and revenue, analyzes inventory levels, identifies the best-selling books, and ranks books based on their revenue.

:sparkles: Features

- Calculate total sales for each book.
- Calculate revenue for each book.
- Extract unique book genres using Set Comprehension.
- Analyze total bookstore inventory and sales.
- Identify the best-selling book.
- Find books with low stock.
- Rank books by total revenue using "sorted()" and "lambda".
- Generate a management report.

🛠️ Python Concepts Used

- Lists and Dictionaries
- Nested Data Structures
- For Loops
- List Comprehension
- Set Comprehension
- Lambda Functions
- "sorted()" and "enumerate()"
- Conditional Filtering
- F-Strings

:arrow_forward:️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python bookstore_analyzer.py

:bar_chart: Sample Analysis

The program generates a report containing:

- Total number of books
- Number of unique genres
- Total available stock
- Total sales
- Total revenue
- Best-selling book
- Top 3 books by revenue
- Low-stock books
- Available genres
